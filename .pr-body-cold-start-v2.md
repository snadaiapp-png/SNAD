## Summary

Adds cold-start forensic instrumentation for Render Free-tier profiling. **No business-logic changes, no security changes, no DB changes.**

## Background

The previous true cold-start test (PR #915 acceptance) revealed:
- Render Free cold start takes **125–282 seconds** (variable)
- The 125s BFF auth budget is exceeded when cold start > 125s
- We have **no visibility** into where the startup time is spent

## Changes

### 1. `SanadPlatformApplication.main()` — attach `BufferingApplicationStartup`

```java
app.setApplicationStartup(new BufferingApplicationStartup(2_000));
app.addListeners(new StartupTimelineLogger());
app.run(args);
```

**Capacity: 2,000 steps** (conservative, to bound memory overhead on Render Free's 512MB instance). Typical SANAD cold start produces ~3-5k steps; the buffer will drop the oldest ~1-3k steps silently if exceeded. Total memory overhead: ~400KB for the buffer + ~1MB transient during dump on ready.

### 2. New `StartupTimelineLogger`

Registered programmatically via `SpringApplication.addListeners()` so it can observe early lifecycle events that fire BEFORE the `ApplicationContext` exists. Captures 5 lifecycle event timestamps and dumps top-30 slowest startup steps + category summary on `ApplicationReadyEvent`.
