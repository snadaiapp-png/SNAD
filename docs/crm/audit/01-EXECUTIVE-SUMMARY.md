## Top Recommendations

1. **Remove `matchIfMissing=true`** from all 5 mock intelligence adapters immediately
2. **Fix SET LOCAL string concatenation** in `TenantRlsConnectionHandler` to use parameterized `SET LOCAL app.tenant_id = ?`
3. **Refactor `LegacyCrmInfrastructureService`** into bounded application services
4. **Fix `TransferUseCases.decide()`** for MULTI_APPROVER or remove the policy option
5. **Add FK constraints and audit columns** to CRM-010 schema via new migration
6. **Sanitize 409/400 error responses** to prevent tenant UUID leakage
7. **Implement event outbox pattern** for customer intelligence events
8. **Address all 15 critical items before beginning CRM-021 (G5)**
