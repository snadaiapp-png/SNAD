## Blocked Findings (historical record)

### HIGH-01: Test Encryption Key Hardcoded as Default

| Field | Value |
|-------|-------|
| **Finding ID** | HIGH-01 |
| **Severity** | HIGH |
| **Category** | Secrets Management |
| **OWASP** | A04: Insecure Design |
| **File** | `application-local.yml:59` |
| **Original Status** | OPEN — No Risk Acceptance |
| **Current Status** | ✅ REMEDIATED (2026-07-31) |

**Remediation (engineering):**
1. `ProductionSecurityGuard` (EnvironmentPostProcessor) — refuses production
   startup when the test default key, a missing key, or an invalid-length key
   is configured.
2. `CrmEncryptionKeyValidator` — shared crypto-layer validation rejecting the
   known test key and trivially weak keys unconditionally in both crypto
   paths (`LegacyEncryptionService`, `LegacyCrmInfrastructureService`).
3. `application-local.yml` — test key default removed; non-prod unconfigured
   → ephemeral random AES-256 key.
4. `application-prod.yml` — production requires `CRM_CUSTOM_FIELD_ENCRYPTION_KEY`.

**Evidence:** `ProductionSecurityGuardTest` 8/8 PASS; `CrmEncryptionKeyValidatorTest` 8/8 PASS.

### HIGH-02: No Startup Guard for Production-Critical Security Features

| Field | Value |
|-------|-------|
| **Finding ID** | HIGH-02 |
| **Severity** | HIGH |
| **Category** | Security Configuration |
| **OWASP** | A04: Insecure Design |
| **Files** | `TenantRlsDataSourcePostProcessor.java`, `CaffeineLoginRateLimiter.java`, `application-prod.yml` |
| **Original Status** | OPEN — No Risk Acceptance |
| **Current Status** | ✅ REMEDIATED (2026-07-31) |

**Remediation (engineering):**
1. `ProductionSecurityGuard` validates, before any bean is created in prod:
   - encryption key present, not test default, valid Base64, valid AES length;
   - `snad.rls.enabled` not explicitly disabled;
   - no sensitive actuator endpoints (`env`, `beans`, `configprops`,
     `heapdump`, `threaddump`, `shutdown`) exposed.
2. Registered in `META-INF/spring.factories` alongside
   `ProductionDatasourceGuard`.
3. `SKIP_SECURITY_GUARD=true` escape hatch is audit-visible (WARN log).

**Evidence:** `ProductionSecurityGuardTest` 8/8 PASS (incl. `blocksOnRlsDisabled`,
`blocksOnSensitiveActuatorEndpoint`).
