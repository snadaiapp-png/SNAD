## Root Cause Analysis

**Problem**: RLS tests (CrmRlsTenantIsolationPostgresTest) were failing because
V20260730_1 (ENABLE RLS) and V20260730_2 (DISABLE RLS) both existed on the
Flyway forward path. When `flyway.migrate()` ran, it executed both in sequence,
leaving RLS silently OFF in every full-migrate environment (including production).

**Root Cause**: V20260730_2 was added as a "rollback" migration but was placed on
the forward path, defeating the CRM-018 defense-in-depth goal.

**Fix**: Remove V20260730_2 from the Flyway forward path. V20260802_1
(RE-ENABLE RLS) was later added as a re-enable migration, ensuring RLS stays
ON in all environments.
