## Summary

Accept Git signature status `E` (signed but key unavailable) as PASS with warning.

## Problem

`git log --format=%G?` returns `E` on CI runners because the committer's GPG public key is not in the local keyring. Status `E` means the commit IS signed, verification is just not possible locally. Previous code rejected `E` as an error.

## Fix

- `G`, `U`, `X`, `Y`, `R` → PASS (verified signature)
- `E` → PASS with warning (signed, key unavailable)
- `N`, `B` → FAIL (unsigned or bad signature)

RULE-001 still fails for N and B.
